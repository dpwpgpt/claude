# Fitness & Nutrition Bot

Личный Telegram-бот — помощник по фитнесу и питанию. Работает полностью
локально, без внешних AI-сервисов: единственный необходимый ключ — токен
Telegram-бота.

## Возможности

Внизу экрана бот показывает постоянное меню из трёх кнопок:

- **🔍 Найти рецепт** — просит ввести ингредиенты и ищет по ним рецепт из
  готового меню (`data/recipes.json`, 64 рецепта: завтраки, перекусы,
  основные блюда), например «курица картофель». Если совпадений несколько —
  список кнопок с названиями, выбираешь и получаешь полный рецепт (состав +
  приготовление).
- **🧮 Рассчитать КБЖУ** / **📝 Записать приём пищи** — просят описать состав
  текстом, например `курица 150 г, рис 100 г, огурец`; бот находит продукты
  в своей базе и считает КБЖУ с учётом веса порции, а под ответом даёт
  кнопку «Записать в дневник».

Ввод состава работает и без кнопок — просто напиши его текстом в любой
момент. Кнопки нужны только для поиска рецепта (без них любой текст
считается описанием съеденного, а не поисковым запросом).

Плюс команды:

- **/profile** — пошаговая настройка профиля (пол, возраст, рост, вес, уровень
  активности, цель) и расчёт суточной нормы КБЖУ (формула Миффлина — Сан
  Жеора).
- **/plan [шаблон]** — составляет рацион на день (завтрак/обед/ужин и
  перекус) под целевые калории и БЖУ из профиля, по одному из готовых
  шаблонов рационов. Без аргумента шаблон подбирается автоматически по
  ближайшему соотношению БЖУ к цели; можно указать явно: `/plan вег` или
  `/plan низкоуглеводный`.
- **/today** — итоги за сегодня: что записано, суммарные КБЖУ и сколько
  осталось до дневной нормы.
- **/recipe <ингредиенты>** — то же самое, что кнопка «Найти рецепт», но
  сразу с запросом одной командой, например `/recipe курица картофель`.

КБЖУ считаются по локальной базе продуктов (`data/foods.json`, ~55
продуктов с калорийностью и БЖУ на 100 г) — без обращения к каким-либо
внешним API. Значения справочные и приблизительные, как в любом
подобном трекере. Распознавание фото меню не поддерживается — только
текстовый ввод состава.

### Расширение базы продуктов

`data/foods.json` — обычный JSON-список. Чтобы добавить продукт, впиши
туда объект вида:

```json
{"name": "Название", "aliases": ["синоним1", "синоним2"], "calories": 100, "protein": 10, "fat": 5, "carbs": 8}
```

Значения — на 100 г продукта. После правки файла бота нужно перезапустить.

### Свои шаблоны рациона

`data/meal_templates.json` — шаблоны для `/plan`. Каждый шаблон — это
набор блюд по приёмам пищи (`Завтрак`/`Обед`/`Ужин`/`Перекус`), где
каждое блюдо ссылается на продукт из `foods.json` по точному имени
(`food`) и весу в граммах (`grams`). При выдаче рациона граммовки
пропорционально масштабируются под целевые калории профиля.

### Своя книга рецептов

`data/recipes.json` — список рецептов для `/recipe`. Каждый рецепт:

```json
{"name": "Название", "category": "завтрак", "portion": "Ваша порция - 200 г", "ingredients": "...", "instructions": "..."}
```

`category` — `завтрак` / `перекус` / `основное` (используется только для
справки, поиск идёт по всем категориям сразу). `portion` необязателен.
Поиск ищет введённые слова как подстроку в названии и составе (с
допуском на окончания русских слов, чтобы «курица» находило и «куриное
филе»), и требует совпадения всех введённых ингредиентов сразу.

## Установка

```bash
cd agents/personal/fitness-nutrition-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

- `TELEGRAM_BOT_TOKEN` — токен, полученный у [@BotFather](https://t.me/BotFather).

Больше ничего настраивать не нужно.

## Запуск

```bash
python main.py
```

Бот запускается в режиме polling.

## Деплой на сервер

Для продакшена — Docker-контейнер с автоперезапуском:

```bash
docker compose up -d --build
```

Подробная пошаговая инструкция для VDS (Ubuntu/Debian): [DEPLOY.md](DEPLOY.md).

## Хранение данных

Профиль пользователя и дневник питания хранятся локально в SQLite
(`fitness_bot.db` по умолчанию, путь настраивается через `BOT_DB_PATH`).
Каждый пользователь Telegram видит только свои данные.

## Структура проекта

```
fitness-nutrition-bot/
├── main.py                # точка входа
├── requirements.txt
├── .env.example
├── data/
│   ├── foods.json          # база продуктов: КБЖУ на 100 г
│   ├── meal_templates.json  # шаблоны рационов для /plan
│   └── recipes.json          # книга рецептов для /recipe
└── src/
    ├── config.py            # загрузка настроек из окружения
    ├── nutrition.py         # расчёт БМР/ТДЕЕ и целевых КБЖУ
    ├── food_db.py            # загрузка базы продуктов, нечёткий поиск по названию
    ├── composition.py         # разбор текста состава ("курица 150г, рис 100г")
    ├── plan_templates.py       # выбор и масштабирование шаблона рациона
    ├── recipes.py               # загрузка книги рецептов, поиск по ингредиентам
    ├── storage.py                # SQLite: профили и дневник питания
    ├── handlers.py                # обработчики команд/сообщений Telegram
    └── bot.py                      # сборка и запуск приложения
```
