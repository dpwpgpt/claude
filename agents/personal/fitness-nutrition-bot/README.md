# Fitness & Nutrition Bot

Личный Telegram-бот — помощник по фитнесу и питанию на базе Claude API.

## Возможности

- **/profile** — пошаговая настройка профиля (пол, возраст, рост, вес, уровень
  активности, цель) и расчёт суточной нормы КБЖУ (формула Миффлина — Сан
  Жеора).
- **Фото меню** — пришли фото меню кафе/ресторана, бот распознает блюда и
  оценит калорийность и БЖУ каждого, с кнопками для записи в дневник.
- **Текстовое описание блюда** — опиши состав приёма пищи текстом
  (например, «куриная грудка 150 г, рис 100 г, овощи») — бот разложит на
  ингредиенты и посчитает КБЖУ.
- **/plan [пожелания]** — составляет рацион на день (завтрак/обед/ужин и
  перекусы) под целевые калории и БЖУ из профиля. Можно добавить пожелания,
  например `/plan без молочки, люблю рыбу`.
- **/today** — итоги за сегодня: что записано, суммарные КБЖУ и сколько
  осталось до дневной нормы.

Оценка КБЖУ выполняется самой моделью Claude по составу блюда — без внешней
базы продуктов, поэтому значения приблизительные.

## Установка

```bash
cd agents/personal/fitness-nutrition-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

- `TELEGRAM_BOT_TOKEN` — токен, полученный у [@BotFather](https://t.me/BotFather).
- `ANTHROPIC_API_KEY` — ключ Anthropic API. Если не задан, будет
  использован профиль `ant auth login` или `ANTHROPIC_AUTH_TOKEN` из
  окружения.

## Запуск

```bash
python main.py
```

Бот запускается в режиме polling. Для продакшена рекомендуется запускать
как systemd-сервис или в Docker-контейнере с автоперезапуском.

## Хранение данных

Профиль пользователя и дневник питания хранятся локально в SQLite
(`fitness_bot.db` по умолчанию, путь настраивается через `BOT_DB_PATH`).
Каждый пользователь Telegram видит только свои данные.

## Структура проекта

```
fitness-nutrition-bot/
├── main.py              # точка входа
├── requirements.txt
├── .env.example
└── src/
    ├── config.py         # загрузка настроек из окружения
    ├── models.py          # Pydantic-схемы для структурированных ответов Claude
    ├── nutrition.py        # расчёт БМР/ТДЕЕ и целевых КБЖУ (без LLM)
    ├── claude_service.py    # обёртка над Claude API (анализ меню, оценка блюда, план)
    ├── storage.py            # SQLite: профили и дневник питания
    ├── handlers.py            # обработчики команд/сообщений Telegram
    └── bot.py                  # сборка и запуск приложения
```
